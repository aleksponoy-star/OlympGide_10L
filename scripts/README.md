Здесь размещены вспомогательные скрипты.
База данных.ру был взят файл со всеми организаторами олимпиад и с пмомщью скрипта подставлена олимпиада к каждому из них.

База данных 3.ру файлы формата .csv были переведены в формат .json с помощью скрипта.
